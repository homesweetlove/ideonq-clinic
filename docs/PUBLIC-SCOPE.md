# Public / private boundary

This repository was created with a **new, unrelated Git history**. It is a separately authored showcase; it is **not** a fork, subtree, or mirror of the private `ideonq-business` repository.

## Explicitly included

- Hand-authored, dependency-free static UI and tests.
- Clearly fictional, in-memory patient and employee labels.
- Product-level descriptions and abstract component boundaries.

## Deliberately excluded

- All private backend source, API route implementations, authentication and authorization logic.
- Database schemas and migrations, encryption code, access logs and security controls.
- Private server addresses, internal filesystem paths, network topology, runtime credentials and secrets.
- Real or copied medical charts, contact lists, employee records, databases, backups or logs.
- Original repository's Git commits, tags, branches, Actions artifacts and release history.
- Screenshots, assets and packages that have not been separately reviewed for disclosure or licensing.

## Release checks

Before any future contribution, confirm that:

1. All names, phone numbers, IDs, dates and clinical notes are invented placeholders.
2. No credentials, API URLs, internal domains, customer names or infrastructure specifics were added.
3. No private Git history or binary assets were copied.
4. The build remains network-free, and CI tests pass.
5. Any third-party assets and dependencies have a suitable redistribution license.

Public visibility is not an assertion of clinical, regulatory, security, or operational readiness. Role switching in the demo is presentation-only. Security boundaries must be enforced on a real server, which is not part of this repository.
