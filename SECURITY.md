# Security and privacy

This repository is a UI demonstration. It has no authentication or medical-data security controls. **Do not enter real personal or patient information.** Interactions are temporary and local to your browser session.

Please do not disclose credentials or medical information in public issues. If you find a potential vulnerability or an unintended sensitive-data disclosure, contact the repository owner privately through their GitHub profile before opening a public report.

No claim of compliance, certification, or fitness for medical use is made.
